## Documentation convention

Every `.md` file in this repo gets a stamp on the line(s) right after its first heading, added or refreshed whenever that file is created or edited:

> **Last updated:** 2026-09-01 (uncommitted — not yet pushed, exists only in this local working tree) · 
**Status:** CURRENT — audit report

- **Last updated** — date of the most recent substantive edit. If the file hasn't been committed/pushed yet, say so explicitly (as above) — an unpushed doc is invisible to the rest of the team, which is exactly what caused the `research/lld.md` mixup (see `research/cleanup-plan.md`).
- **Status** — one of `CURRENT`, `PARTIALLY SUPERSEDED`, `SUPERSEDED by <file>`, `STALE`, `HISTORICAL / REFERENCE ONLY`, `MINIMAL / PLACEHOLDER`, or `UNUSED / EMPTY`, plus a short reason.
